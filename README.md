# 🌐 Cyber World Search Engine

A powerful, self-hosted search engine built with Python that can crawl websites and provide search functionality.

![Python Version](https://img.shields.io/badge/python-3.6+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## Features

- 🕷️ **Web Crawling** - Automatically crawl and index websites
- 🔍 **Smart Search** - Advanced ranking algorithms
- 📊 **Analytics** - Search statistics and history
- 💾 **SQLite Database** - Efficient data storage
- 🚀 **Easy to Use** - Simple command-line interface
- 🌐 **Cross-Platform** - Works on Windows, Mac, and Linux
